# GOG Studio

A one-person game studio making small arcade games.

## Ninja Cat: Tree Climb

A vertical arcade climber. A ninja cat leaps between trees, dodging enemy ninjas and traps on the way up. Your score is the height you reach.

- App Store (iPhone): [https://apps.apple.com/app/id6823829181](https://apps.apple.com/app/id6823829181)
- Google Play (Android): [https://play.google.com/store/apps/details?id=com.gogstudio.ninjacat2026](https://play.google.com/store/apps/details?id=com.gogstudio.ninjacat2026)
